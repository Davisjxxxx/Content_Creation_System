# QA and Certification Checklist

## Framework QA
- [ ] all Python files compile
- [ ] unit tests pass
- [ ] agent registry contains every required role
- [ ] every registered prompt path exists
- [ ] every agent declares required inputs and output keys
- [ ] orchestration fails closed on invalid agent output
- [ ] story budget fails closed above hard limit
- [ ] certification blocks missing sources/claims
- [ ] edge claims require competing explanations
- [ ] LinkedIn remains out of v1 scope
- [ ] blog remains adapter-only future scope

## Research QA
- [ ] source URL resolves
- [ ] event date distinguished from publication date
- [ ] consequential claims traced to earliest available primary source
- [ ] secondary-source independence assessed
- [ ] benchmark type identified
- [ ] vendor claims labeled
- [ ] contradictory evidence included
- [ ] stale/recycled story test passed

## Production QA
- [ ] script claim map matches certification
- [ ] no claim-maturity drift
- [ ] first-person claims backed by creator/project evidence
- [ ] visual provenance complete
- [ ] synthetic evidence risk labeled
- [ ] captions checked
- [ ] aspect ratio/crop-safe zones checked
- [ ] audio/video integrity checked
- [ ] platform metadata reviewed

## Final certification
- [ ] adversarial review blocking findings resolved
- [ ] security review completed
- [ ] human reviewer signs QA
- [ ] certification record stored
- [ ] live publishing remains disabled until explicit enablement
